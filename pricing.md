# Pricing — NightPDF

NightPDF is a free tool built for the community. There are no hidden costs, subscriptions, or "pro" tiers.

## Free Plan
- **Price:** $0/month
- **Limits:** Unlimited PDFs, Unlimited file size (limited only by your browser's memory)
- **Features:** 
    - Full Dark Mode conversion
    - Batch processing
    - Native text selection
    - 100% Privacy (Local processing)
    - PWA Installation

## Enterprise / Team
- **Price:** $0
- **Support:** Community-based via GitHub issues.
